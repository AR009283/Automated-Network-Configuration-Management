# Automated Network Configuration Management

## 📌 Project Overview

This project demonstrates a beginner-friendly network automation solution using **Python and Cisco Packet Tracer**.

The Python program automatically generates configuration files for routers and switches, reducing repetitive manual configuration tasks.

The network topology is designed and tested using Cisco Packet Tracer.

## 🎯 Objectives

- Automate repetitive network configuration tasks
- Generate router and switch configuration files
- Automate VLAN configuration generation
- Generate SSH configuration commands
- Maintain organized network configuration files
- Reduce manual configuration errors
- Practice Python programming with networking concepts

## 🛠️ Technologies Used

- Python
- Cisco Packet Tracer
- Cisco IOS
- Networking fundamentals
- VLAN
- SSH
- IP Addressing
- Routing

## 🏗️ Network Topology

The project contains multiple Cisco routers and switches connected through different networks.

The topology includes:

- R-01
- R-03
- R-04
- R-05
- R-06
- Multiple switches and PCs
